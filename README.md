# Personal Portfolio Website

## Overview

This project is a professional personal portfolio website designed to showcase technical skills, projects, achievements, career goals, and contact information in a clean and modern format. The website highlights development experience, GitHub repositories, and future career aspirations in Information Technology and Cybersecurity.

The portfolio was built to create a strong professional online presence while demonstrating front-end web development skills and responsive design practices.

---

# Features

* Responsive and modern website layout
* Professional hero section with headshot
* GitHub repository integration
* Technical skills showcase
* Projects section with descriptions
* Contact and social media links
* Smooth navigation and animations
* Mobile-friendly design
* Clean and organized UI/UX

# Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/portfolio-website.git
```

## 2. Open the Project Folder

```bash
cd portfolio-website
```

## 3. Run the Website

Open the `index.html` file in your browser.

# GitHub Repository Integration

The portfolio dynamically displays GitHub repositories using the GitHub API.

Update the GitHub username inside the JavaScript file:

```javascript
const username = "YOUR_GITHUB_USERNAME";
```
